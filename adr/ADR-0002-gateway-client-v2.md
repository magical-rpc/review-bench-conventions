# ADR-0002: переход на GatewayClientV2

Статус: принято 2026-03-04.

## Контекст
V1 не принимает идемпотентный ключ, поэтому ретрай по таймауту создавал
второй возврат. Инцидент INC-214: двойной возврат на 12 400 руб.

## Решение
Новые вызовы только через `GatewayClientV2`. V1 выводится из эксплуатации
в первом квартале: список сервисов на V1 ведётся в этом репозитории.

## Последствия
Каждая бизнес-операция несёт ключ идемпотентности, ключ строится
из номера операции, а не из времени вызова.
