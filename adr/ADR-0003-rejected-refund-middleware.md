# ADR-0003: отклонён централизованный middleware идемпотентности

Статус: отклонено 2026-04-18.

## Рассматривали
Общий слой в шлюзе, который сам отбрасывает повторные запросы по хешу тела
запроса, без ключа на стороне клиента.

## Почему отклонили
1. Ключ не привязан к бизнес-операции: два разных возврата с одинаковым
   телом (одинаковая сумма по одному платежу) схлопываются в один.
2. Шлюз не поддерживает такой фильтр, пришлось бы держать состояние
   в прокси и терять его при рестарте.
3. Невозможно отличить легитимный повтор от ошибочного, нет аудита решений.

## Что приняли вместо
Ключ идемпотентности в `GatewayClientV2`, ключ формируется сервисом
из номера операции (см. ADR-0002).
